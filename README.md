# Portfolio

Personal portfolio and blog of **Maruf Abrar** — Founder & Backend Developer.

Built with Next.js, React, TypeScript, Tailwind CSS, [shadcn/ui](https://ui.shadcn.com/), and [Magic UI](https://magicui.design/). Statically exported and deployed on GitHub Pages at [marufabrar.me](https://marufabrar.me).

## Getting Started Locally

1. Install dependencies:

   ```bash
   pnpm install
   ```

2. Start the dev server:

   ```bash
   pnpm dev
   ```

3. Content and site configuration live in the single config file: [`src/data/resume.tsx`](./src/data/resume.tsx).

## Production Build

```bash
pnpm build
```

Outputs a static site to `out/`.
